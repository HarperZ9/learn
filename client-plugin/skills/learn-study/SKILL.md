# learn-study

Use when the user requests practice planning or review of their own learning attempts. Start with learn_status and learn_doctor. Use learn_tutor_plan only after the user asks to create a study session; it writes local state. Record only the user's actual practice answers. Never produce, hint, or auto-fill answers to a certified or graded assessment. Mastery reports describe witnessed practice attempts, not credentials. Real course execution and browser actuation stay operator-driven on the CLI. Inspect receipts before claiming completion. No bundled model or provider account is included.
